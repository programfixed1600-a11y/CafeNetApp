# کافی‌نت آنلاین — پروژهٔ اندروید (WebView)

نرم‌افزار سفارش خدمات کافی‌نت، بسته‌بندی‌شده برای اندروید.
تمام رابط کاربری (فارسی، راست‌به‌چپ) داخل فایل `app.html` است و برنامه فقط آن را به‌صورت
تمام‌صفحه و با پشتیبانی از آپلود فایل نمایش می‌دهد.

## ساختار پروژه

```
cafenet-android/
├── app.html                      ← کل برنامه (همان فایل تحویلی، بدون تغییر)
├── android/                      ← پروژهٔ Android Studio
│   ├── app/
│   │   ├── build.gradle.kts
│   │   └── src/main/
│   │       ├── AndroidManifest.xml
│   │       ├── assets/app.html          ← برنامهٔ داخل اپ
│   │       ├── java/com/cafenetonline/app/MainActivity.kt
│   │       └── res/                     ← آیکون‌ها، تم، نام برنامه
│   ├── settings.gradle.kts
│   └── build.gradle.kts
└── .github/workflows/build-apk.yml      ← ساخت خودکار APK در GitHub
```

## روش ۱ — ساخت APK بدون نصب هیچ چیز (پیشنهادی و رایگان)

1. در سایت `github.com` یک حساب بساز و یک مخزن (Repository) جدید و **عمومی** بساز.
2. کل محتوای همین پوشه را در مخزن آپلود کن (دکمهٔ Add file ← Upload files).
3. بعد از آپلود، به تب **Actions** برو ← گردش‌کار «Build APK» خودش اجرا می‌شود
   (اگر اجرا نشد: کلید Run workflow را بزن).
4. حدود ۳ تا ۵ دقیقه صبر کن. زیر بخش **Artifacts** فایل `cafenet-online-apk.zip` را
   دانلود کن؛ داخلش فایل `app-debug.apk` است.
5. همان فایل را روی گوشی اندروید نصب کن (اجازهٔ «نصب از منابع نامعلوم» لازم است).

نتیجه: فایل نصبی آماده، بدون اینکه چیزی روی کامپیوتر خودت نصب کنی.

## روش ۲ — ساخت APK با Android Studio (روی کامپیوتر خودت)

1. Android Studio (نسخهٔ Hedgehog یا جدیدتر) را نصب کن.
2. `File ← Open` و پوشهٔ `android/` را باز کن. اجازه بده Gradle Sync تمام شود.
3. برای تست سریع: `Run ▶` روی شبیه‌ساز یا گوشی وصل‌شده.
4. برای فایل نصبی امضاشده:
   `Build ← Generate Signed Bundle / APK ← APK`
   کلید جدید بساز (Keystore)، رمزها را جایی امن نگه دار، گزینهٔ **release** را انتخاب کن.
5. خروجی اینجاست:
   `android/app/build/outputs/apk/release/app-release.apk`

> برای تست بدون امضا هم `Build ← Build Bundle(s) / APK(s) ← Build APK(s)` کافی است.

## روش ۳ — Capacitor (اگر بعداً خواستی نسخهٔ بومی‌تر با نوتیفیکیشن و دوربین)

```bash
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "کافی نت آنلاین" com.yourname.cafenet --web-dir=www
# app.html را داخل پوشهٔ www بگذار و نامش را index.html بگذار
npx cap add android
npx cap open android     # Android Studio باز می‌شود ← Build APK
```

## قسمت‌هایی که هنوز باید به سرور وصل شوند

این نسخه سفارش‌ها را در حافظهٔ خود گوشی نگه می‌دارد. برای محصول واقعی:

| بخش | پیشنهاد |
|-----|----------|
| حساب کاربری و پایگاه‌داده | Firebase Auth + Firestore |
| آپلود مدارک | Firebase Storage یا ابر آروان (با محدودیت حجم و رمزگذاری) |
| پرداخت | درگاه زرین‌پال یا آیدی‌پی |
| پیامک و اطلاع‌رسانی | کاوه‌نگار یا ملی‌پیامک |

## نکات انتشار

- **گوگل‌پلی:** از ۳۱ آگوست ۲۰۲۶ اپ‌های جدید باید حداقل `targetSdk 36` (اندروید ۱۶) باشند.
- **محدودیت ایران:** گوگل برای توسعه‌دهندگان ساکن ایران امکان احراز هویت نمی‌دهد؛ در نتیجه
  انتشار در گوگل‌پلی عملاً ممکن نیست. بازارهای داخلی (کافه‌بازار، مایکت) و پخش مستقیم APK
  راه واقع‌بینانه است.
- **سیاست حفظ حریم خصوصی اجباری است** چون کد ملی و مدارک جمع می‌کنی.
- فرم **Data Safety** گوگل و توضیح شفاف دربارهٔ نگهداری مدارک را جدی بگیر.
- کلید امضا (Keystore) را گم نکن؛ بدون آن نمی‌توانی نسخهٔ جدید منتشر کنی.

## تغییر محتوای برنامه

هر تغییری در رابط کاربری، خدمات، قیمت‌ها یا متن‌ها لازم داشتی، فقط فایل
`app.html` را ویرایش کن و **همان را در دو جا** به‌روز کن:

- `app.html` (ریشه)
- `android/app/src/main/assets/app.html`

سپس دوباره APK بساز.

## ویرایش قیمت‌ها (مهم)

همهٔ قیمت‌ها فقط در یک بلوک در ابتدای کد فایل `app.html` جمع شده‌اند:

```js
const PRICE_DEFAULTS = {
  "s1":  [235000, "ردیف ۸ — ثبت ثنا و احراز هویت"],
  "s53": [10000,  "ردیف ۳۶ — پرینت لیزری سیاه‌وسفید A4"],
  // ...
};
```

- برای به‌روز کردن نرخنامه: فقط عددها را عوض کن و فایل را دوباره ذخیره کن.
- بدون دست‌زدن به کد: داخل خود برنامه، تب **مدیریت ← ویرایش قیمت‌ها**، هر قیمت را عوض کن.
  این تغییرات در حافظهٔ دستگاه ذخیره می‌شود.
- «خروجی گرفتن» یک فایل `cafenet-prices.json` می‌دهد؛ با «برگرداندن از فایل» می‌توانی
  همان را (بعد از ویرایش) به همهٔ دستگاه‌ها برگردانی.
- به‌روزرسانی خودکار: در همان بلوک، متغیر `PRICE_SOURCE_URL` را به آدرس یک فایل JSON بده؛
  هر بار برنامه باز شود، قیمت‌ها از آن خوانده می‌شود.

اگر با نرخنامهٔ جدید، فایل `app.html` را عوض کردی، یادت باشد همان را در
`android/app/src/main/assets/app.html` هم کپی کنی و دوباره APK بسازی.

## مالکیت نرم‌افزار (مهم)

در ابتدای کد `app.html` یک بلوک به نام `OWNER` هست. تمام تماس‌ها، دکمهٔ واتس‌اپ،
صفحهٔ «تماس با ما» و پیام سفارش‌ها به همین اطلاعات وصل است:

```js
const OWNER = {
  name:  "کافی‌نت مرکزی",
  phone: "09120000000",
  whatsapp: "989120000000",   // با کد کشور، بدون + و بدون صفر
  telegram: "",               // اختیاری
  address: "نشانی مرکز",
  hours: "شنبه تا پنجشنبه، ۹ تا ۲۱",
  adminPass: "1405"           // رمز ورود به پیشخوان مدیریت
};
```

هر کسی این برنامه را نصب کند، سفارشش مستقیم برای همین مرکز می‌آید و
پیشخوان مدیریت با رمز قفل است؛ پس کسی نمی‌تواند قیمت‌ها را عوض کند یا
سفارش‌ها را ببیند. مشخصات را می‌توان از داخل برنامه هم ویرایش کرد:
**مدیریت ← مشخصات من**.
